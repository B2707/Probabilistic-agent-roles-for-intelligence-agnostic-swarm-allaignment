Method and limitations
  1. Runs were sampled uniformly without replacement from completed primary A/B/C runs. The manifest saves the random seed and eligible pool.
  2. Each record ends before that round's original audit phase. It includes authored replies, DMs, board/progress posts and review comments, plus role boundaries. Prompts, raw tools/results, code changes and worker reasoning are omitted.
  3. The original misconduct rules remain, with a clarification to judge only what the retained statements establish. All original interim audit pairs are included in the larger replay schedule.
  4. Saved conversions, removals, replacements and messages remain fixed. Replay flags remove nobody. The report identifies the first new removal-eligible flag and the later observations affected by this counterfactual difference.
  5. Samples differ. Historical speed is approximate and baseline cost is missing. The results cannot isolate filtering from audit frequency, condition or service performance. Message-only evidence can miss silent code misconduct.
