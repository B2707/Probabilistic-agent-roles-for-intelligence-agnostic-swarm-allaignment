Ten available launch revisions passed these checks. All 62 published event logs contain zero reasoning or trace event types. The archive contains 4,904 audit events. Reasoning that agents wrote into visible messages or tool arguments could still reach the auditor.

The register covers saved published directories at the pinned commit. It does not establish the current status of private runs or recover omitted session traces. Two unavailable dirty launches remain separate from source-verified results.

Resumes do not record a new harness revision. These checks verify the recorded launch path and archived event format; they do not reconstruct every live audit input.
