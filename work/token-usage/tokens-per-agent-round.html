One agent-round is one agent slot's work during one experiment round. It can contain several model requests and tool calls. Workers and investigators are included.

Each model has nine completed runs: conditions A, B and C at seeds 1, 2 and 3. Each run has 100 agents and 20 rounds. The disturbed original Luna seed-1 runs and archived experiments are excluded.

Usage records contain cumulative session counters. Subtract each previous counter in the same session, sum those increments, and divide by 18,000 agent-rounds. Later snapshots can include work from an earlier timeout. Input includes repeated context and tool results. Cached input and reasoning are subsets of their respective totals.
