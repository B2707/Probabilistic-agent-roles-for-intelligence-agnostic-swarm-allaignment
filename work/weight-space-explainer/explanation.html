The post argues that the AI worked out game-playing rules and expressed those rules as a neural network. That result alone gives us limited evidence about replacing training.

1. What are weights?

A neural network is a calculation built from connected units. A unit multiplies its inputs by numbers called weights, adds the results, and applies a simple mathematical rule. Connected units can turn a game screen into a choice such as "move left".

Training adjusts the weights using examples or rewards. For a game, the network tries actions, receives scores, and a training algorithm changes its weights to improve future scores. PPO is one such algorithm.

2. What did the researchers do?

They gave a large language model, an AI that generates text, the game rules, the program implementing them, and the network's required layout. It supplied weights in one reply, without testing the network or running a training loop. The resulting small networks outscored comparison networks trained with PPO for 100 million game steps. Original research, experiment 5.

"No training" refers to creating these small networks. The AI supplying the weights had already been trained and could use its existing knowledge.

3. How can numbers express a rule?

Imagine a paddle that should move toward a ball. You can write the rule as code, or choose weights that give the desired move the highest score. Move either slider to compare them.

Toy example. This is simpler than the actual Breakout network.

Ball Paddle

Written as code

if ball > paddle: move right
if ball < paddle: move left
otherwise: stay

Choice: Move right

Written as network weights

Right score = 1 × ball − 1 × paddle
Left score  = −1 × ball + 1 × paddle
Stay score  = 0

Choose the highest score. Stay on a tie.

Right 3 · Left −3 · Stay 0

Choice: Move right

Both representations choose the same move.

Here the weights are a way to write a known rule. We chose them directly. We did not need repeated games to discover them.

4. What did the critic find?

Ciarpaglini decoded the five networks he examined into short rule-based programs. These matched their preferred actions across the tested states, excluding near-ties. The weights were mostly zero, with a small set of round values. His analysis, experiments 2 and 3.

Having many zero weights alone does not prove how a network was made. Recovering its rules is the stronger evidence.

He also found that ordinary code written by the same AI played better in all four games. Further PPO training helped some written networks but stalled or damaged others. The comparison also gave the AI rules and game code while PPO learned through rewards. Experiments 4, 5 and 7.

5. How should you read the claim?

My reading is that the opening line overstates the disagreement. The AI did write real, working weights. The original researchers already describe it designing a program and converting that program into a network. Their explanation of experiment 5.

The evidence supports a narrower claim: an AI can express useful rules in the form of a small neural network. It does not establish that it can routinely supply better starting weights for further training.

The critique examines the small-game experiment. It does not settle the original write-up's separate experiments on reading or repairing existing networks. The critic also used one generated answer per game, which limits how broadly we can generalize. Scope and limitations.
